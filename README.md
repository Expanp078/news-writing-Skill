# 新闻稿写作Skill
Release：alpha1.2

---
该Skill是我探索LLM学习和应用能力的一个尝试。LLM虽然具有广泛的世界知识，但在特定专业领域的工作能力难以形成如人类一样的知识学习、内化和迁移运用的能力，总是只能遵循一套固定模式进行尝试。

虽然预训练模型没有办法像人类一样改变神经网络模式，但通过文档存储和Skill设计，我尝试让LLM模仿人类的学习模式，以观察他的工作能力变化。该新闻稿写作Skill就是一个尝试。

>**相关书籍清单**
>
> 1. 《新华社新闻报道中的禁用词和慎用词》新华社
> 2. 《传播学教程（第2版）》郭庆光
> 3. 《语法修辞讲话》吕叔湘、朱德熙
> 4. 《新闻报道与写作》梅尔文·门彻
> 5. 《新闻写作教程》刘明华、徐泓、张征
> 6. 《新闻学概论》李良荣
> 7. 《新闻的十大基本原则：新闻从业者须知和公众的期待（第三版）》比尔·科瓦奇、汤姆·罗森斯蒂尔
> 8. 《新闻写作方法论》艾丰
> 9. 《中国新闻采访写作学》刘海贵
> 10. 《写作法宝：非虚构写作指南》威廉·津瑟
> 11. 《〈华尔街日报〉是如何讲故事的》威廉·E. 布隆代尔
>
>为避免版权问题，书籍本身相关内容已在Skill中删除，只保留LLM对其的学习后形成的笔记。

## 补充说明
该Skill只是一个非常早期的尝试，各方面问题还很多。成品虽然不够好，但也超出我的最低预期，达到了一个勉强可用的状态，证明了上述方案的可行性。这个Skill本是帮助我的朋友完成他的一些工作上的任务而帮忙制作的，但一不留神就做了很多尝试。在将来应该能吸收一些其他Skill的设计经验，或许可以达到更好的效果。
